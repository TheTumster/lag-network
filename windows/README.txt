laG Network
===========

START.bat   Starts the whole network (proxy + hub + factions + smp). First run downloads Java if needed.
TUNNEL.bat  Lets friends join without touching your router (free, via playit.gg).

Join yourself:   localhost
Make yourself admin: in the "laG hub" window type:   op YourName   (do the same in factions and smp)

Change memory / ports / the network name: network.json
Stop: type  stop  in each server window, and  end  in the proxy window.
